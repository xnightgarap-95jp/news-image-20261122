# news-image-20261122

One image that sums up the world news of Sunday 22 November 2026, drawn by
a Python program using only the standard library.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png` (1024x1024 PNG). Run it as many times as you
like: the output is byte-identical every time.

## The image

A newspaper front page for the day:

- **Lead:** Iran's early-Sunday missile and drone wave at US bases in
  Kuwait and Bahrain.
- **Top right:** COP31 nears a final deal in Antalya; Hong Kong votes for
  its Election Committee.
- **Bottom left:** a magnitude 4.1 earthquake shakes Myanmar in the early
  hours.
- **Bottom right:** also today — Australia faults a US report on AUKUS,
  25 deported migrants arrive in Liberia, Trump warns Iran's leaders.

See `NEWS.md` for the stories and their sources.

## Files

- `main.py` — the drawing program (stdlib only: `zlib`, `struct`, `os`).
- `NEWS.md` — the stories depicted, each backed by at least two reports.
- `entry.png` — the rendered image.
- `LICENSE` — MIT.
